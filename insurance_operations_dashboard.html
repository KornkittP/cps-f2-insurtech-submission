Privacy rules, assumptions & limitations

Names reveal the first character of each component; emails preserve the first and last local-part characters and domain (short or invalid addresses are withheld). The bundled expiry records contain only masked holder fields. Uploaded raw fields are processed locally and not retained in application state. Customer text is pattern-redacted for common email, phone and ID formats, then only exact approved generic mock phrases are displayed; all other text is withheld. This intentionally sacrifices recall for privacy. No network calls, storage, analytics or external libraries are used.

This browser-only prototype is not a production security boundary, does not implement RBAC, and cannot guarantee detection of all PII. A production version needs server-side validation, access control and approved free-text review. Premium is recorded premium, not collected revenue. Duplicate policy identifiers are rejected. Dates are interpreted as calendar dates in the supplied reporting context (Asia/Bangkok assumed).
